Why Graphical Models?

Key idea: Use graphs to represent probability distributions

  • Nodes = random variables
  • Edges = cause/effect or mutual influence relationships
  • Structure reveals independence properties

Why?

  • Represent complex probabilistic relationships in high dimensions
  • Represent conditional independence
  • Enable efficient inference and learning
  • Foundational in modern ML: model description, sampling, variational inference

Three Types of Graphical Models

  1. Bayesian Networks (Directed)
    • Directed acyclic graphs (DAGs)
    • Natural for causal relationships
  2. Markov Random Fields (Undirected)
    • Undirected graphs
    • Suitable for co-influence, non-causal relationships
    • Example: Image pixels, social networks
  3. Factor Graphs
    • Flexible representation for both BN and MRF

Bayesian Networks

Definition: A Bayesian network consists of:

  • A directed acyclic graph (DAG) $G$
  • Nodes $x_1,\ldots,x_m$ represent random variables
  • Edges represent direct dependencies

Key property - Factorization:

\[p(x_1,\ldots,x_m) = \prod_{i=1}^{m} p(x_i | \pa(x_i))\]

where $\pa(x_i)$ = parents of $x_i$ in $G$

$p(x_1,x_2,x_3,x_4) = p(x_1)p(x_2|x_1)p(x_3|x_1)p(x_4|x_1,x_3)$

From a complete graph to a smaller Bayesian Network

Complete Graph:

\[\begin{aligned} p(x_1,x_2,x_3,x_4) &= p(x_1)p(x_2|x_1)\\ &\phantom{=}\textcolor{#0000FF}{p(x_3|x_1,x_2)}\\ &\phantom{=}\textcolor{#FF0000}{p(x_4|x_1,x_2,x_3)} \end{aligned}\]

No independence: Can represent any distribution

Bayesian Network:

\[\begin{aligned} p(x_1,x_2,x_3,x_4) &= p(x_1)p(x_2|x_1)\\ &\phantom{=}\,\textcolor{#0000FF}{p(x_3|x_1)}\\ &\phantom{=}\,\textcolor{#FF0000}{p(x_4|x_1,x_3)} \end{aligned}\]

Encodes: $x_3 \independent x_2 | x_1$ and $x_4 \independent x_2 | x_1,x_3$

Key insight: BNs obtained by removing missing edges $\rightarrow$ independence

Example: Traffic and Punctuality

  • $T$: Traffic (heavy or not)
  • $A$: Alice late (yes/no)
  • $B$: Bob late (yes/no)
  • $C$: Charlie (Bob's son) late (yes/no)

Factorization:

\[p(T,A,B,C) = p(T) \cdot p(C) \cdot p(A|T) \cdot p(B|T,C)\]

Conditional Independence in BNs

Key Question: Given a BN, when is $X \independent Z | Y$?

Three basic structures:

  1. Chain: $X \to Y \to Z$
    • $X \not\independent Z$ (information flows through $Y$)
    • $X \independent Z | Y$ ($Y$ blocks info flow; it already provides all information in $X$ relevant to $Z$)
  2. Fork: $X \leftarrow Y \to Z$
    • $X \not\independent Z$ (common cause induces dependence)
    • $X \independent Z | Y$ ($Y$ blocks info flow)
  3. Collider (v-structure): $X \to Y \leftarrow Z$
    • $X \independent Z$ (independent causes)
    • $X \not\independent Z | Y$ (conditioning bounces info back along the path)

Collider example: Talent $\to$ Success $\leftarrow$ Luck

Observing success induces dependence between talent and luck

d-Separation

General rule for independence: d-separation

Sets of RVs $\mathcal{X}$ and $\mathcal{Z}$ are d-separated by $\mathcal{Y}$ if every path between $\mathcal{X}$ and $\mathcal{Z}$ is blocked by $\mathcal{Y}$

A path is blocked by $\mathcal{Y}$ if:

  • The path contains a chain $\cdots \to Y \to \cdots$ or fork $\cdots \leftarrow Y \to \cdots$ where $Y \in \mathcal{Y}$, OR
  • The path contains a collider $\cdots \to Y \leftarrow \cdots$ where $Y \notin \mathcal{Y}$ and no descendant of $Y$ is in $\mathcal{Y}$

Theorem: If $\mathcal{X}$ and $\mathcal{Z}$ are d-separated by $\mathcal{Y}$, then

\[\mathcal{X} \independent \mathcal{Z} | \mathcal{Y}\]

for any distribution that factorizes according to the graph.

d-Separation Examples

A path is blocked by $\mathcal{Y}$ if it has a node $Y$ that is:

  • in a chain $\to Y \to$ or a fork $\leftarrow Y \to$, with $Y \in \mathcal{Y}$
  • a collider $\to Y \leftarrow$, with neither $Y$ nor a descendant of $Y$ in $\mathcal{Y}$

Example 1: Is $T \independent C$ in the traffic network?

Yes! $B$ blocks the path

Example 2: Is $A \independent B | T$?

Yes! Path $A \leftarrow T \to B$ is blocked by $T$ (chain)

Example 3: Is $A \independent B$ (unconditionally)?

No! Path $A \leftarrow T \to B$ is not blocked (nothing in conditioning set)

d-Separation: Collider Example

Example 4: Is $T \independent C | B$?

No! Path $T \to B \leftarrow C$ has collider $B$

$B$ is in conditioning set $\to$ path is not blocked!

Key insight: Observing $B$ creates dependence!

  • If Bob is late, either traffic was heavy OR Charlie biked
  • Knowing traffic helps predict Charlie's choice

Example 5: Is $A \independent \{B,C\} | T$?

Yes! All paths from $A$ to $\{B,C\}$ go through $T$, which blocks them

d-Separation: More Examples

Example 6: Complex network

  • Is $A \independent B$? Yes!
  • Is $A \independent B | D$? No! Path $A \to C \to D \leftarrow B$
    has collider $D$, which we observe $\to$ opens path
  • Is $A \independent B | E$? No! Path $A \to C \to D \to E$
    has a collider with descendant $E$ observed $\to$ opens path
  • Is $A \independent E | D$? Yes! Path blocked at $D$

d-Separation: Real-World Example

Questions:

  1. Are Genes and Smoking independent?
    Yes!
  2. Are X-ray and Dyspnea independent?
    No! Path X-ray $\leftarrow$ Cancer $\to$ Dyspnea (fork)
  3. Are X-ray and Dyspnea independent given Cancer?
    Yes! Cancer blocks the only path
  4. Are Genes and Smoking independent given Cancer?
    No! Cancer is collider, observing it opens path!
    (Explaining away: if cancer and non-smoker $\to$ likely genetic)

Markov Blanket

Markov Blanket of node $X$: minimal set that makes $X$ independent of all other nodes

Markov Blanket of $X$ = {parents, children, co-parents}

Above: $\mb(X) = \{p_1, p_2, c_1, c_2, s\}$

Property: $X \independent \text{(all other nodes)} | \mb(X)$

Critical for: Gibbs sampling (sample each variable given its Markov blanket)

Markov Models: Chain Bayesian Networks

Sequential data: Many processes evolve over time

  • Weather prediction: today's weather $\to$ tomorrow's
  • Stock prices, speech recognition, gene sequences

Markov property: Future depends only on present

\[p(x_t | x_1, \ldots, x_{t-1}) = p(x_t | x_{t-1})\]

This is just a chain Bayesian Network!

Factorization:

\[p(x_1, \ldots, x_T) = p(x_1) \prod_{t=2}^T p(x_t | x_{t-1})\]

Markov Model Example: Weather

Consider a Markov chain $x_1\to x_2 \to x_3 \to \cdots$ modeling daily weather; each $x_t$ can be ☀️ Sunny, ☁️ Cloudy, 🌧️ Rainy. These are the states.

Transition probabilities: $p(x_t | x_{t-1})$. Can be shown as a graph or matrix if independent of $t$:

Example: $p(x_1 = {}$☀️$, x_2 = {}$☁️$, x_3 = {}$🌧️$) = p(x_1 = {}$☀️$) \times 0.2 \times 0.3$

Graph above is NOT a GM. It's a state transition graph

Example: Hidden Markov Models

Problem: Often we don't observe states directly!

Examples:

  • Speech: Hidden = phonemes, Observed = acoustic signals
  • Robot localization: Hidden = position, Observed = sensors
  • Bioinformatics: Hidden = DNA structure, Observed = measurements

Solution: Hidden Markov Model (another special BN!)

Factorization:

\[p(x_{1:T}, z_{1:T}) = p(z_1) p(x_1|z_1) \prod_{t=2}^T p(z_t|z_{t-1}) p(x_t|z_t)\]

Gray nodes = observed, white nodes = hidden

HMM Example: Robot Localization

Scenario: Robot in hallway uses sensors to figure out location

Hidden states: Position $z_t \in \{$Room 1, Room 2, Room 3$\}$

Observations: Sensor $x_t \in \{$🚪 door, 🧱 wall$\}$

Transitions: $p(z_t | z_{t-1})$

\[\begin{bmatrix} 0.7 & 0.3 & 0 \\ 0.2 & 0.6 & 0.2 \\ 0 & 0.3 & 0.7 \end{bmatrix}\]

Robot mostly stays put, sometimes moves to adjacent room

Emissions: $p(x_t | z_t)$

\[\begin{bmatrix} 0.9 & 0.1 \\ 0.2 & 0.8 \\ 0.8 & 0.2 \end{bmatrix}\]

Rooms 1,3: usually see door
Room 2: usually see wall

Key question: Given sensor sequence, where is robot?

Answer: Use BN inference! (Forward algorithm, Viterbi, etc.)

Bayesian Networks: Applications in Modern ML

Classical Applications:

  • Medical Diagnosis: Symptom → Disease reasoning with uncertainty
  • Speech Recognition (HMMs): Foundation of early systems (now replaced by deep learning, but concepts persist)

Modern Applications:

  • Causal Inference: Discovering cause-effect relationships from data
  • Reinforcement Learning: MDPs and POMDPs for sequential decisions
  • Probabilistic Programming: Flexible Bayesian models (Pyro, Stan)
  • Explainable AI: Interpretable reasoning under uncertainty

Connection to Deep Learning:

  • Variational Autoencoders (VAEs) = neural nets + latent variable models
  • Bayesian neural networks use same inference principles (VI, MCMC)

Introduction to Markov Random Fields

Recall: Bayesian Networks use directed edges for causal relationships

But what if relationships are symmetric/non-causal?

Examples:

  • Images: Adjacent pixels tend to have similar colors
  • Social networks: Friends tend to have similar opinions
  • Spatial data: Nearby locations have correlated properties

Solution: Markov Random Fields (MRFs)

  • Use undirected graphs
  • Edges represent mutual influence or correlation, not causation

Key difference:

  • BN: "Traffic may cause Alice to be late"
  • MRF: "Alice and Bob are friends, influencing each others' opinions"

Motivating Example: Political Affiliations

Question: Given a friendship network, how can we model political affiliations, knowing that friends tend to share similar views?

Setup: Each person $x_i \in \{0, 1\}$ (party affiliation); Edges = friendships

Goal: Define $p(x_1, \ldots, x_5)$ that assigns higher probability to configurations where friends agree

Challenge: No natural causal direction $\Rightarrow$ BN doesn't fit well!

MRF Solution: Potential Functions

Idea: Define potential functions that favor agreement

Pairwise potential (for edges):

\[\psi_{ij}(x_i, x_j) = \begin{cases} 1 & x_i = x_j \\ 0.5 & x_i \neq x_j \end{cases}\]

Friends agreeing is twice as “compatible”

Applies to edges: $(1,2), (1,4), (3,4)$

Triple potential (for clique $\{2,3,5\}$):

\[\psi_{235}(x_2, x_3, x_5) = \begin{cases} 1 & \text{all same} \\ 0.3 & \text{one differs} \end{cases}\]

Three mutual friends have stronger group dynamics!

Note: $x_2, x_3, x_5$ form a clique (all pairwise connected)

Key insight: Potentials are NOT probabilities—they encode “compatibility” of configurations

MRF Solution: The Distribution

Distribution: Product of all potentials, normalized

\[p(x_1,\ldots,x_5) = \frac{1}{Z} \psi_{12} \cdot \psi_{14} \cdot \psi_{34} \cdot \psi_{235}\]

where $Z = \displaystyle\sum_{\text{all } 2^5 \text{ configs}} \psi_{12} \cdot \psi_{14} \cdot \psi_{34} \cdot \psi_{235}$  (partition function)

Configuration on the left is 2.4 times more likely than the right!

Result: Configurations where friends agree have higher probability! ✓

MRF: Formal Definition

Markov Random Field consists of:

  • Undirected graph $G$ with nodes $x_1, \ldots, x_m$
  • Potential functions $\psi_C(x_C)$ for each clique $C$
  • Partition function $Z$ for normalization

Factorization:

\[p(x_1, \ldots, x_m) = \frac{1}{Z} \prod_{C \in \text{cliques}} \psi_C(x_C)\]

where $Z = \sum_{x_1, \ldots, x_m} \prod_{C} \psi_C(x_C)$

Key concepts:

  • Clique: Set of nodes with edges between all pairs
  • Potential $\psi_C$: Non-negative function encoding compatibility
    • Higher values = more “compatible” configurations
    • NOT probabilities (don't need to sum to 1)
  • Partition function $Z$: Normalizes to make it a valid distribution
    • Often intractable to compute!

Independence in Markov Random Fields

MRF independence rule: Simpler than BNs!

Theorem (Global Markov Property):

For disjoint sets $A$, $B$, $C$, if $C$ separates $A$ from $B$ (removing $C$ disconnects $A$ and $B$), then:

\[A \independent B | C\]

Energy-Based Models

Consider MRF with potentials $\psi_C(x_C) > 0$.

Key insight: Take the logarithm!

\[p(\bx) = \frac{1}{Z} \prod_{C} \psi_C(x_C) = \frac{1}{Z} \exp\left( \sum_C \log \psi_C(x_C) \right) = \frac{1}{Z} \exp\left( -E(\bm{x}) \right)\]

where $E(\bm{x}) = -\sum_C \log \psi_C(x_C)$ is the energy function

Energy-Based Model (EBM):

\[\boxed{p(\bm{x})\propto e^{-E(\bm{x})}}\]
  • Low energy $\Leftrightarrow$ High probability (preferred configurations)
  • High energy $\Leftrightarrow$ Low probability (unlikely configurations)
  • Finding most likely state = minimizing energy
  • $\nabla_x \log p(x) = -\nabla_x E(x)$ : score function

Application: Image Denoising with MRFs

Task: Remove noise from black/white image

Setup:

  • $x_i \in \{-1, +1\}$: true pixel
  • $y_i \in \{-1, +1\}$: observed noisy pixel
  • Neighboring pixels tend to have same color

Energy function:

\[E(x, y) = -\sum_i \alpha_i x_i - \sum_{(i,j) \in \text{neighbors}} \beta_{ij} x_i x_j - \sum_i \zeta_i x_i y_i\]
  • $\alpha_i$: bias for pixel $i$ ($\alpha_i > 0$ favors $x_i=+1$)
  • $\beta_{ij} > 0$: neighbors prefer to match
  • $\zeta_i > 0$: assumes noise is less likely than correct observation

Denoising: Find $\arg\max_x p(x | y)$ (balance smoothness + observation)

Simulation: Denoising by Iterated Conditional Modes

$\zeta$ noise $p$ sweeps

Slide 28's energy with $\alpha_i = 0$, $\beta_{ij} = 1$, $\zeta_i = \zeta$. Visit the pixels in turn, giving each its lower-energy value given the rest:

$x_i \leftarrow \operatorname{sign}\big(\sum_{j \in N(i)} x_j + \zeta\, y_i\big)$ (a tie keeps $x_i$)

No step raises $E(x, y)$, so ICM stops at a local minimum.

One sweep with $\zeta = 2.5$: a pixel changes only if all its neighbors disagree with it

A second sweep changes nothing: a local minimum

$\zeta = 1$: three disagreeing neighbors overrule $y_i$; less noise is left, but the eyebrows erode

$\zeta > 4$: no neighborhood overrules $y_i$, so $x = y$

Key insight:

  • BNs: "Parent causes child" $\to$ $p(\text{child}|\text{parent})$
  • MRFs: "Neighbors correlate" $\to$ $\psi(\text{neighbors})$

Can convert between them:

  • BN $\to$ MRF: "Moralization" (connect parents, drop directions)
  • MRF $\to$ BN: Not always possible (may lose independence)

Summary: Graphical Models

Three types of graphical models:

  • Bayesian Networks: Directed graphs for causal relationships
    • Factorization: $p(x_1,\ldots,x_m) = \prod_i p(x_i | \pa(x_i))$
    • Examples: Traffic model, Markov chains, HMMs
  • Markov Random Fields: Undirected graphs for correlations
    • Factorization: $p(x_1,\ldots,x_m) = \frac{1}{Z}\prod_C \psi_C(x_C)$
    • Examples: Image denoising, social networks

Independence properties:

  • d-separation: Determines all conditional independence in BNs
  • Markov blanket: Minimal conditioning set for independence
  • Graph structure reveals independence $\to$ enables efficient computation

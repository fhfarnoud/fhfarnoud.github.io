Ridge regression: solution

\[\cL(\btheta)=\|\by-X\btheta\|_2^2+\lambda\|\btheta\|_2^2.\]
\[\nabla\cL(\btheta)=-2X^T(\by-X\btheta)+2\lambda\btheta.\]
\[\nabla\cL(\widehat{\btheta})=0\quad\Longleftrightarrow\quad(X^TX+\cpr{\lambda I})\widehat{\btheta}=X^T\by.\]
\[\boxed{\widehat{\btheta}_{\rm ridge}=(X^TX+\cpr{\lambda I})^{-1}X^T\by}.\]

$\displaystyle\widehat{\btheta}_{\rm LS}=(X^TX)^{-1}X^T\by.$Only the added $+\lambda I$ changes the system.

With $X^TX=I$: $\widehat{\btheta}_{\rm LS}=X^T\by$ and $\widehat{\btheta}_{\rm ridge}=\frac{1}{1+\lambda}X^T\by$.

 3 minutes. Have students supply the penalty gradient. Reveal one algebraic step at a time. Multiplication by X transpose collects residual contributions across observations. Unlike OLS, the ridge residual need not be orthogonal to every design column: X transpose residual=lambda theta. OLS inverse requires full column rank; the next slide removes that restriction for positive lambda.

When Labels Are Missing

Goal. Learn the parameters $\theta$ of two Gaussian classes.

\[\begin{gathered} \begin{aligned} p(Y_i=1)&=\pi, & (\mathbf X_i\mid Y_i=1)&\sim\mathcal N(\boldsymbol\mu_1,K_1)\\[-3pt] p(Y_i=0)&=1-\pi, & (\mathbf X_i\mid Y_i=0)&\sim\mathcal N(\boldsymbol\mu_0,K_0) \end{aligned}\\[-7pt] \theta=(\pi,\boldsymbol\mu_0,\boldsymbol\mu_1,K_0,K_1) \end{gathered}\]

Assume independent observation-label pairs.

\[\ell_c(\theta;\mathbf x,\mathbf y)=\log p(\mathbf x,\mathbf y;\theta) =\sum\nolimits_{i=1}^n\log p(\mathbf x_i,y_i;\theta)\]

Maximum-likelihood (MLE) solution

Let $n_0$ and $n_1$ be the class counts. Then $\hat\pi=n_1/n$.

\[\hat{\boldsymbol\mu}_0=\frac{1}{n_0}\sum\nolimits_{i:y_i=0}\mathbf x_i,\qquad \hat{\boldsymbol\mu}_1=\frac{1}{n_1}\sum\nolimits_{i:y_i=1}\mathbf x_i\] \[\begin{aligned} \hat K_0&=\frac{1}{n_0}\sum\nolimits_{i:y_i=0} (\mathbf x_i-\hat{\boldsymbol\mu}_0)(\mathbf x_i-\hat{\boldsymbol\mu}_0)^\top\\ \hat K_1&=\frac{1}{n_1}\sum\nolimits_{i:y_i=1} (\mathbf x_i-\hat{\boldsymbol\mu}_1)(\mathbf x_i-\hat{\boldsymbol\mu}_1)^\top \end{aligned}\]

We can no longer apply these MLE formulas directly because we don’t know which observations belong to each class.

Complete and Incomplete Data

Let $\mathbf x=(\mathbf x_1,\ldots,\mathbf x_n)$ denote all observed feature vectors, $\mathbf y=(y_1,\ldots,y_n)$ all class labels, and $\theta$ the model parameters.

Complete data $(\mathbf x,\mathbf y)$

\[\ell_c(\theta;\mathbf x,\mathbf y)=\log p(\mathbf x,\mathbf y;\theta)\]

Both features and class labels are observed.

We can estimate the Gaussian parameters using the MLE formulas from the previous slide.

Observed data $\mathbf x$, unknown labels $\mathbf y$

\[\ell(\theta;\mathbf x)=\log p(\mathbf x;\theta)\]

Only the features are observed.

We must account for the unknown labels when estimating the parameters.

Our goal is still to estimate $\theta$ by maximum likelihood, but now we must do so without knowing the labels.

Marginalizing Hidden Variables

Observed-data likelihood

Sum over all label assignments $\mathbf y\in\mathcal Y^n$, where $\mathcal Y$ is the finite set of possible labels.

\[L(\mathbf x;\theta)=p(\mathbf x;\theta) =\sum_{\mathbf y\in\mathcal Y^n}p(\mathbf x,\mathbf y;\theta)\]

Observed-data log-likelihood

\[\ell(\theta;\mathbf x)=\log\sum_{\mathbf y\in\mathcal Y^n}\prod_{i=1}^n p(\mathbf x_i,y_i;\theta)\] Use independence for the joint density.
\[\phantom{\ell(\theta;\mathbf x)}=\log\prod_{i=1}^n\left(\sum_{k\in\mathcal Y}p(\mathbf x_i,Y_i=k;\theta)\right)\] Factor the sum over assignments into a product of per-point sums.
\[\phantom{\ell(\theta;\mathbf x)}=\sum_{i=1}^n\log\left(\sum_{k\in\mathcal Y}p(\mathbf x_i,Y_i=k;\theta)\right)\] Expand the log of the product. Each sum stays inside its log.
The likelihood can be evaluated efficiently, but the logarithm of a sum makes maximization more difficult.

If we knew $\theta$

We could infer the missing labels using Bayes’ rule.

\[p(y_i\mid\mathbf x_i;\theta)\propto p(\mathbf x_i\mid y_i;\theta)p(y_i;\theta)\]

If we knew $\mathbf y$

We could estimate $\theta$ using the familiar MLE formulas.

Can we alternate between inferring the missing labels and updating the model parameters?

Reveal that intermediate step on its own. Take the log of the resulting product. The inner sums remain inside the logarithms, so the terms for different classes cannot be optimized separately as in the labeled problem. The EM Idea

Start with an initial parameter estimate $\theta^{(0)}$. At iteration $t$, $\theta^{(t)}$ is our current estimate.
Let $\mathbf x$ be the observed data and $\mathbf y$ a possible assignment of the missing labels.

Hold $\theta^{(t)}$ fixed.
Use Bayes’ rule to calculate the probabilities of possible label assignments.

\[\theta^{(t)}\longrightarrow p(\mathbf y\mid\mathbf x;\theta^{(t)})\]

Hold these probabilities fixed.
Maximize the expected complete-data log-likelihood to update the parameters.

\[p(\mathbf y\mid\mathbf x;\theta^{(t)})\longrightarrow\theta^{(t+1)}\]
Repeat: Use the updated parameters to estimate the missing labels again, then update the parameters.

Next show which function this procedure improves.

Why a Lower Bound?

Why should alternating label estimation and parameter updates improve the log-likelihood?

\[\ell(\theta;\mathbf{x})=\log p(\mathbf{x};\theta) =\log\sum_{\mathbf{y}}p(\mathbf{x},\mathbf{y};\theta)\]

The log of a sum makes direct maximization harder. Write $\ell(\theta)$ for short.

Use a simpler lower bound $B_t(\theta)$.

\[\textcolor{#762A83}{B_t(\theta)}\leq \textcolor{#008000}{\ell(\theta)}\]

Make it touch at the current estimate.

\[B_t(\theta^{(t)})=\ell(\theta^{(t)})\]

Move to the maximum of this bound.

\[\theta^{(t+1)}=\arg\max_\theta B_t(\theta)\]
━ $\ell(\theta)$ ━ $B_t(\theta)$ ● Current estimate ◆ Bound maximum ○ New likelihood
How does the posterior distribution give us a bound that touches at the current estimate?

Deriving the Lower Bound

Let $\mathbf Y$ represent the missing labels. Choose any probability distribution $q(\mathbf y)$ over their possible assignments, supported where the posterior is positive.

\[\ell(\theta)\]
\[{}=\ln p(\mathbf x;\theta) =\ln\frac{p(\mathbf x,\mathbf y;\theta)}{p(\mathbf y\mid\mathbf x;\theta)}\]

Bayes’ rule.

\[{}=\sum\nolimits_{\mathbf y}q(\mathbf y) \ln\frac{p(\mathbf x,\mathbf y;\theta)}{p(\mathbf y\mid\mathbf x;\theta)}\]

Average over assignments. The log ratio is constant and $\sum_{\mathbf y}q(\mathbf y)=1$.

\[{}\mathrel{\textcolor{#762A83}{\geq}}\sum\nolimits_{\mathbf y}q(\mathbf y) \ln\frac{p(\mathbf x,\mathbf y;\theta)}{p(\mathbf y\mid\mathbf x;\theta)} - D\bigl(q\,\|\,p(\mathbf Y\mid\mathbf x;\theta)\bigr)\]

KL divergence is nonnegative.

\[{}=\sum\nolimits_{\mathbf y}q(\mathbf y) \ln\frac{p(\mathbf x,\mathbf y;\theta)}{p(\mathbf y\mid\mathbf x;\theta)} -\sum\nolimits_{\mathbf y}q(\mathbf y) \ln\frac{q(\mathbf y)}{p(\mathbf y\mid\mathbf x;\theta)}\]

Definition of KL divergence.

\[{}=\textcolor{#762A83}{\underbrace{ \sum\nolimits_{\mathbf y}q(\mathbf y)\ln p(\mathbf x,\mathbf y;\theta) -\sum\nolimits_{\mathbf y}q(\mathbf y)\ln q(\mathbf y) }_{\mathcal L(q,\theta)}}\]

Expand the logarithms and cancel the posterior terms.

We have constructed a lower bound $\mathcal L(q,\theta)$. When does it become tight?
4 min. Bayes’ rule gives the same ratio for each assignment with positive posterior probability. Averaging the log ratio under q leaves its value unchanged. Subtract a nonnegative divergence to create the inequality. Expand the divergence and point to the two posterior log terms that cancel. Throughout, sums weighted by q can be taken over its positive-probability assignments. The subtracted divergence is the gap between the log-likelihood and the resulting bound. Ask how to make it zero at the current estimate.

When Is the Bound Tight?

If the bound touches the log-likelihood at our current estimate, maximizing it guarantees nondecreasing log-likelihood.

\[\textcolor{#2354A8}{B(\theta^{(t)},\theta^{(t)})=\ell(\theta^{(t)})}\]

The KL gap is zero if and only if the two distributions are equal. Choose the posterior at the current estimate.

\[\boxed{q(\mathbf y)=p(\mathbf y\mid\mathbf x;\theta^{(t)})}\]
━ $\ell(\theta)$━ $B(\theta,\theta^{(t)})$● Current estimate
\[\ell(\theta)\geq \textcolor{#762A83}{B(\theta,\theta^{(t)})} =\sum\nolimits_{\mathbf y}p(\mathbf y\mid\mathbf x;\theta^{(t)})\ln p(\mathbf x,\mathbf y;\theta) -\sum\nolimits_{\mathbf y}p(\mathbf y\mid\mathbf x;\theta^{(t)})\ln p(\mathbf y\mid\mathbf x;\theta^{(t)})\]
The second term is constant in $\theta$. Maximizing the bound is equivalent to maximizing its first term.
\[\begin{aligned} Q(\theta,\theta^{(t)}) &=\sum_{\mathbf y}p(\mathbf y\mid\mathbf x;\theta^{(t)})\ln p(\mathbf x,\mathbf y;\theta)\\[6pt] &\boxed{Q(\theta,\theta^{(t)})=\mathbb E_{\theta^{(t)}}\!\left[\ln p(\mathbf x,\mathbf Y;\theta)\mid\mathbf x\right]} \end{aligned}\]
\[\boxed{\theta^{(t+1)}=\arg\max_\theta Q(\theta,\theta^{(t)})}\]
3 min. Start at the blue contact point. The old likelihood equals the height of the bound there. Advance one iteration to rebuild the bound and move the contact point, then reset. At the current estimate, choosing its posterior makes the KL gap zero. Substitute that posterior into both sums from the previous slide. Point out that only the candidate inside the first log changes during maximization. On the next slide we write the same fixed posterior more compactly as q sub t and view Q as an expectation.

The EM Algorithm

Start with an initial estimate $\theta^{(0)}$. At each iteration $t$, perform two steps.

1. Expectation step

Use the current estimate to compute the expected complete-data log-likelihood.

\[Q(\theta,\theta^{(t)})=\mathbb E_{\theta^{(t)}}\! \left[\ln p(\mathbf x,\mathbf Y;\theta)\mid\mathbf x\right]\]

Build a bound that touches $\ell$ at $\theta^{(t)}$.

2. Maximization step

Maximize $Q$ over the candidate $\theta$ to update the estimate.

\[\theta^{(t+1)}=\arg\max_{\theta}Q(\theta,\theta^{(t)})\]
━ $\ell(\theta)$ ● Current estimate ━ $B(\theta,\theta^{(t)})$ ◆ Bound maximum ○ Updated $\ell$
Repeat. Use the updated parameters to construct a new lower bound and maximize it again.

Gaussian Mixture Model

Return to the two Gaussian classes with missing labels.

\[\begin{gathered} \begin{aligned} p(Y_i=1)&=\pi, & (\mathbf X_i\mid Y_i=1)&\sim\mathcal N(\boldsymbol\mu_1,K_1)\\[-3pt] p(Y_i=0)&=1-\pi, & (\mathbf X_i\mid Y_i=0)&\sim\mathcal N(\boldsymbol\mu_0,K_0) \end{aligned}\\[-7pt] \theta=(\pi,\boldsymbol\mu_0,\boldsymbol\mu_1,K_0,K_1) \end{gathered}\]

Let $f_k(\mathbf x)=\mathcal N(\mathbf x;\boldsymbol\mu_k,K_k)$. The joint density is

\[p(\mathbf x_i,y_i;\theta) =[\pi f_1(\mathbf x_i)]^{y_i} [(1-\pi)f_0(\mathbf x_i)]^{1-y_i}\]

For independent observations, the complete-data log-likelihood is

\[\begin{aligned} \ell_c(\theta;\mathbf x,\mathbf y) &=\sum\nolimits_{i=1}^{n}\ln p(\mathbf x_i,y_i;\theta)\\ &=\sum\nolimits_{i=1}^{n}\big[ y_i\ln(\pi f_1(\mathbf x_i))\\ &\qquad +(1-y_i)\ln((1-\pi)f_0(\mathbf x_i))\big] \end{aligned}\]

The original observations, with labels hidden

Without the labels, we must sum over all possible label assignments, making direct maximization of the observed-data likelihood difficult.
7 min. Return to the original unlabeled observations and recall the Gaussian class model. For the joint density, substitute each possible label and observe which factor remains. Independence turns the joint density into a product across observations. Take logs and explain how the indicator exponents become coefficients. Without the labels, marginalizing gives the observed-data likelihood discussed earlier. Ask which quantity replaces each indicator in the expectation step.

E-Step

Using the current parameter estimate $\theta^{(t)}$, compute the expected complete-data log-likelihood.

\[Q(\theta,\theta^{(t)})=\mathbb E_{\theta^{(t)}}[\ln p(\mathbf x,\mathbf Y;\theta)\mid\mathbf x]\]

Definition of $Q$.

\[\phantom{Q(\theta,\theta^{(t)})}{}= \mathbb E_{\theta^{(t)}}\!\left[\sum\nolimits_{i=1}^n\ln p(\mathbf x_i,Y_i;\theta)\mid\mathbf x\right] =\sum\nolimits_{i=1}^n\mathbb E_{\theta^{(t)}}[\ln p(\mathbf x_i,Y_i;\theta)\mid\mathbf x_i]\]

Independence of observation-label pairs and linearity of expectation.

\[\phantom{Q(\theta,\theta^{(t)})}{}= \sum\nolimits_{i=1}^n\mathbb E_{\theta^{(t)}}\!\left[ Y_i\ln\!\big(\pi f_1(\mathbf x_i)\big) +(1-Y_i)\ln\!\big((1-\pi)f_0(\mathbf x_i)\big) \mid\mathbf x_i\right]\]

Substitute the complete-data log-likelihood.

\[\phantom{Q(\theta,\theta^{(t)})}{}= \sum\nolimits_{i=1}^n\!\Big[ \underbrace{\mathbb E_{\theta^{(t)}}[Y_i\mid\mathbf x_i]}_{\gamma_i} \ln\!\big(\pi f_1(\mathbf x_i)\big) +\underbrace{\mathbb E_{\theta^{(t)}}[1-Y_i\mid\mathbf x_i]}_{1-\gamma_i} \ln\!\big((1-\pi)f_0(\mathbf x_i)\big)\Big]\]

Linearity of expectation. Only $Y_i$ is random.

\[\kern-0.3em\boxed{Q(\theta,\theta^{(t)})= \sum\nolimits_{i=1}^n\!\Big[ \gamma_i\ln\!\big(\pi f_1(\mathbf x_i)\big) +(1-\gamma_i)\ln\!\big((1-\pi)f_0(\mathbf x_i)\big)\Big]}\]

Substitute posterior expectations.

where \[\gamma_i=\mathbb E_{\theta^{(t)}}[Y_i\mid\mathbf x_i]\]
The E-step replaces the missing labels with their posterior expectations.
3 min. Start from the definition of Q. The joint density factors over independent observation-label pairs, and the posterior of each label only uses its own observed feature vector. Use linearity to take the sum outside the expectation. Substitute the joint log-density from the previous slide and pull out the fixed log terms. End by identifying gamma i as the posterior expectation of the label. The next slide shows how to compute it.

E-Step: Responsibilities

\[\kern-0.3em\boxed{Q(\theta,\theta^{(t)})= \sum\nolimits_{i=1}^n\!\Big[ \gamma_i\ln\!\big(\pi f_1(\mathbf x_i)\big) +(1-\gamma_i)\ln\!\big((1-\pi)f_0(\mathbf x_i)\big)\Big]}\]
where \[\gamma_i=\mathbb E_{\theta^{(t)}}[Y_i\mid\mathbf x_i] =p(Y_i=1\mid\mathbf x_i;\theta^{(t)})\]

$Y_i$ is binary.

\[\phantom{\gamma_i}{}= \frac{p(\mathbf x_i,Y_i=1;\theta^{(t)})} {p(\mathbf x_i,Y_i=1;\theta^{(t)})+p(\mathbf x_i,Y_i=0;\theta^{(t)})}\]

Bayes’ rule and marginalization.

\[\phantom{\gamma_i}{}= \frac{\pi^{(t)}f_1^{(t)}(\mathbf x_i)} {\pi^{(t)}f_1^{(t)}(\mathbf x_i)+(1-\pi^{(t)})f_0^{(t)}(\mathbf x_i)}\]

Substitute the Gaussian mixture model.

$\gamma_i$, called the responsibility, represents the probability that observation $\mathbf x_i$ belongs to class 1 given the current parameter estimate $\theta^{(t)}$.

The E-step partially assigns each observation to class 1 with weight $\gamma_i$ and to class 0 with weight $1-\gamma_i$.
3 min. Recall where the posterior expectations enter Q. The expected binary indicator is the posterior probability of class 1. Apply Bayes’ rule, sum over the two labels in the denominator, and substitute the two weighted Gaussian densities. Point to the iteration superscripts in the responsibility and their absence inside the log terms of Q. For the M-step, keep these soft assignments fixed while varying the candidate parameters.

M-Step: Weights and Means

Hold the responsibilities fixed and maximize $Q(\theta,\theta^{(t)})$ over the candidate parameters.

\[\boxed{Q(\theta,\theta^{(t)})=\sum\nolimits_{i=1}^n\!\Big[ \gamma_i\big(\htmlClass{em-mstep-weight-term}{\ln\pi}+\htmlClass{em-mstep-density-term}{\ln f_1(\mathbf x_i)}\big) +(1-\gamma_i)\big(\htmlClass{em-mstep-weight-term}{\ln(1-\pi)}+\htmlClass{em-mstep-density-term}{\ln f_0(\mathbf x_i)}\big) \Big]}\]

Mixing weight

\[\frac{\partial Q}{\partial\pi}= \sum_{i=1}^n\left(\frac{\gamma_i}{\pi}-\frac{1-\gamma_i}{1-\pi}\right)=0\]
\[\boxed{\pi^{(t+1)}=\frac1n\sum_{i=1}^n\gamma_i}\]

Gaussian means

\[f_k(\mathbf x_i)=\mathcal N(\mathbf x_i;\boldsymbol\mu_k,K_k) =\frac{\exp\!\left(\htmlClass{em-mstep-dependent}{ -\frac12(\mathbf x_i-\boldsymbol\mu_k)^\top K_k^{-1}(\mathbf x_i-\boldsymbol\mu_k)}\right)} {(2\pi)^{d/2}|K_k|^{1/2}},\quad k=0,1\]
\[\frac{\partial Q}{\partial\boldsymbol\mu_1} =\frac{\partial}{\partial\boldsymbol\mu_1} \sum\nolimits_{i=1}^n\gamma_i\ln f_1(\mathbf x_i)\]
\[\phantom{\frac{\partial Q}{\partial\boldsymbol\mu_1}}{}= \frac{\partial}{\partial\boldsymbol\mu_1}\sum\nolimits_{i=1}^n\gamma_i \left(-\frac12(\mathbf x_i-\boldsymbol\mu_1)^\top K_1^{-1}(\mathbf x_i-\boldsymbol\mu_1)\right)\]
\[\phantom{\frac{\partial Q}{\partial\boldsymbol\mu_1}}{}= \sum\nolimits_{i=1}^n\gamma_i K_1^{-1}(\mathbf x_i-\boldsymbol\mu_1)=0\]
\[\boxed{\boldsymbol\mu_1^{(t+1)}=\frac{\sum_i\gamma_i\mathbf x_i}{\sum_i\gamma_i}}\]
\[\boxed{\boldsymbol\mu_0^{(t+1)}=\frac{\sum_i(1-\gamma_i)\mathbf x_i}{\sum_i(1-\gamma_i)}}\]
The mixing weight is the average responsibility. Each mean is a responsibility-weighted sample mean.

Direct Maximum Likelihood

\[X=S+\epsilon,\qquad S\sim\mathcal N(0,\theta),\qquad \epsilon\sim\mathcal N(0,\sigma^2)\]

Since $S$ and $\epsilon$ are independent Gaussians,

\[\begin{aligned} &X\sim\mathcal N(0,\theta+\sigma^2)\\[5pt] &\Longrightarrow\quad \ell(\theta)=\ln p(x;\theta) =-\frac12\ln[2\pi(\theta+\sigma^2)]-\frac{x^2}{2(\theta+\sigma^2)} \end{aligned}\]

Maximizing with respect to $\theta\geq0$,

\[\begin{aligned} &\frac{d\ell}{d\theta}=-\frac{1}{2(\theta+\sigma^2)} +\frac{x^2}{2(\theta+\sigma^2)^2}=0\\[9pt] &\Longrightarrow\quad \boxed{\hat\theta_{\mathrm{ML}}= \begin{cases} x^2-\sigma^2,& x^2\geq\sigma^2\\ 0,& x^2<\sigma^2 \end{cases}} \end{aligned}\]
Observation $x$ Noise variance $\sigma^2$
We can solve this problem directly. Can EM recover the same estimate?

E-Step for the Hidden Signal

\[Z=(S,\epsilon),\quad X=S+\epsilon,\qquad S\sim\mathcal N(0,\theta),\quad\epsilon\sim\mathcal N(0,\sigma^2)\]

$\doteq$ denotes equality up to terms independent of the candidate $\theta$.

\[Q(\theta,\theta^{(t)})=\mathbb E_{\theta^{(t)}}[\ln p(Z;\theta)\mid X=x]\]

General definition of $Q$.

\[\phantom{Q(\theta,\theta^{(t)})}{}= \mathbb E_{\theta^{(t)}}[\ln p(S;\theta)+\ln p(\epsilon)\mid X=x]\]

Independence of signal and noise.

\[\phantom{Q(\theta,\theta^{(t)})}{}\doteq \mathbb E_{\theta^{(t)}}[\ln p(S;\theta)\mid X=x]\]

The noise distribution does not depend on $\theta$.

\[\phantom{Q(\theta,\theta^{(t)})}{}\doteq \mathbb E_{\theta^{(t)}}\!\left[-\frac{\ln\theta}{2}-\frac{S^2}{2\theta}\,\middle|\,X=x\right]\]

Substitute the Gaussian log-density and drop terms independent of $\theta$.

\[\phantom{Q(\theta,\theta^{(t)})}{}= \boxed{-\frac{\ln\theta}{2}-\frac{\mathbb E_{\theta^{(t)}}[S^2\mid X=x]}{2\theta}}\]

Linearity of expectation. $\theta$ is deterministic and only $S$ is random.

The E-step reduces to computing the posterior second moment of the hidden signal, $\mathbb E_{\theta^{(t)}}[S^2\mid X=x]$.
2 min. The complete-data density factors because the signal and noise are independent before observing their sum. The noise term’s expectation can depend on the current estimate through the posterior and is constant in the candidate. Substitute the Gaussian log-density for positive candidate theta. For each fixed candidate, the expectation averages over the hidden signal under the current estimate, so log theta and the coefficient of S squared can come outside. Retain both terms for the M-step, where the candidate varies. The next slide computes the posterior second moment.

M-Step

Recall from the E-step
\[Q(\theta,\theta^{(t)})\doteq -\frac{\ln\theta}{2}-\frac{\mathbb E_{\theta^{(t)}}[S^2\mid X=x]}{2\theta}\]

Maximize $Q$

Differentiating with respect to $\theta$,

\[\frac{\partial Q}{\partial\theta}=-\frac{1}{2\theta} +\frac{\mathbb E_{\theta^{(t)}}[S^2\mid X=x]}{2\theta^2}=0\] \[\boxed{\theta^{(t+1)}=\mathbb E_{\theta^{(t)}}[S^2\mid X=x]}\]

Instead of using the unobserved $S^2$, we use its posterior expectation.

Compute the Conditional Second Moment

Since $S$ and $X=S+\epsilon$ are jointly Gaussian,

\[\operatorname{Cov}_{\theta^{(t)}}(S,X)=\theta^{(t)},\qquad \operatorname{Var}_{\theta^{(t)}}(X)=\theta^{(t)}+\sigma^2\]

Using the conditional Gaussian distribution,

\[S\mid X=x;\theta^{(t)}\sim\mathcal N\left( \frac{\theta^{(t)}}{\theta^{(t)}+\sigma^2}x,\, \frac{\theta^{(t)}\sigma^2}{\theta^{(t)}+\sigma^2}\right)\]

Therefore,

\[\begin{aligned} \theta^{(t+1)}&=\mathbb E_{\theta^{(t)}}[S^2\mid X=x]\\[8pt] &=\operatorname{Var}_{\theta^{(t)}}(S\mid X=x) +\mathbb E_{\theta^{(t)}}[S\mid X=x]^2 \end{aligned}\]
\[\theta^{(t+1)}= \left(\frac{\theta^{(t)}}{\theta^{(t)}+\sigma^2}\right)^2x^2 +\frac{\theta^{(t)}\sigma^2}{\theta^{(t)}+\sigma^2}\]
3 min. With a positive current estimate, the posterior second moment is positive and fixed while differentiating Q in the candidate theta. The derivative changes from positive to negative at that moment, giving the maximum. Compare the update with the complete-data estimate S squared. The conditional mean coefficient is covariance divided by observed variance. The conditional variance is the signal variance minus the squared covariance divided by the observed variance. Add the variance and the squared mean to obtain the second moment and substitute both into the update.

When the E-Step Is Hard

Recall that the E-step computes

$\displaystyle Q(\theta,\theta^{(t)})=\sum\nolimits_{\mathbf y} \underbrace{\htmlClass{em-inference-emphasis}{p(\mathbf y\mid\mathbf x;\theta^{(t)})}}_{\text{Posterior}} \ln p(\mathbf x,\mathbf y;\theta)$ $\displaystyle {}=\sum\nolimits_{\mathbf y} \frac{p(\mathbf x,\mathbf y;\theta^{(t)})} {\underbrace{\htmlClass{em-inference-emphasis}{\textstyle\sum_{\mathbf y'}p(\mathbf x,\mathbf y';\theta^{(t)})}} _{\text{Potentially expensive to compute}}} \ln p(\mathbf x,\mathbf y;\theta)$

Tractable Inference

The posterior factorizes.

\[p(\mathbf y\mid\mathbf x;\theta^{(t)})=\prod\nolimits_{i=1}^{n}p(y_i\mid\mathbf x_i;\theta^{(t)})\]

Compute each responsibility independently.

$O(n)$

Computational cost
Fixed component count and observation dimension.

Potentially Intractable Inference

The posterior generally does not factorize.

\[p(\mathbf y\mid\mathbf x;\theta^{(t)})\ne\prod\nolimits_{i=1}^{n}p(y_i\mid\mathbf x_i;\theta^{(t)})\]

For $n$ binary labels, $\sum_{\mathbf y\in\{0,1\}^n}p(\mathbf x,\mathbf y;\theta^{(t)})$ has $2^n$ terms.

$O(2^n)$

Naive enumeration
Joint label assignments.

What if we cannot compute the exact posterior expectations required by the E-step?
2 min. Recall that the posterior sets the weights in Q. Use Bayes’ rule and point to the sum in the denominator, which is shared by the posterior probabilities. In the independent mixture, the joint factors by pair and the denominator factors into local normalizers, so each responsibility can be computed separately. Recall that Gaussian conditioning gave the posterior for signal plus noise in closed form. Then compare the arrows between hidden nodes on the right. The normalization sum for binary labels has two choices per variable. The exponential count applies to enumeration. Chain structure, for example, allows efficient reuse of partial sums. End by asking how to proceed when computing the required posterior expectations is too expensive.

From EM to Variational Inference

Recall that we introduced an arbitrary distribution $q(\mathbf y)$ over the hidden variables to construct a lower bound.

\[\ln p(\mathbf x;\theta)= \underbrace{\sum\nolimits_{\mathbf y}q(\mathbf y) \ln\tfrac{p(\mathbf x,\mathbf y;\theta)}{q(\mathbf y)}}_{\mathcal L(q,\theta)\text{ (Evidence Lower Bound, ELBO)}} +\underbrace{D_{\mathrm{KL}}\big(q\|p(\cdot\mid\mathbf x;\theta)\big)}_{\text{Gap}}\]

For fixed $\theta$,

\[\boxed{\max\nolimits_q\mathcal L(q,\theta)\quad\Longleftrightarrow\quad \min\nolimits_q D_{\mathrm{KL}}\big(q\|p(\cdot\mid\mathbf x;\theta)\big)}\]
━ True posterior $q$

Exact E-Step

Choose the exact posterior.

\[q^{(t)}(\mathbf y)=p(\mathbf y\mid\mathbf x;\theta^{(t)})\]
\[D_{\mathrm{KL}}=0\qquad Q(\theta,\theta^{(t)})=\mathbb E_{q^{(t)}}[\ln p(\mathbf x,\mathbf Y;\theta)]\]

The lower bound is tight at $\theta^{(t)}$.

Variational Inference

Restrict $q$ to a tractable family $\mathcal Q$.

\[q^{(t)}=\operatorname*{arg\,max}\nolimits_{q\in\mathcal Q}\mathcal L(q,\theta^{(t)})\]
\[D_{\mathrm{KL}}\geq 0\qquad q^{(t)}(\mathbf y)\approx p(\mathbf y\mid\mathbf x;\theta^{(t)})\]

The lower bound may no longer be tight.

Key advantage. Evaluate the ELBO using the joint $p(\mathbf x,\mathbf y;\theta)$ and $q(\mathbf y)$, bypassing posterior normalization.

Instead of computing the exact posterior, we optimize a tractable approximation by maximizing the lower bound.
3 min. Recall that q is any distribution over the hidden variables. The sum is for discrete variables, and the density plots illustrate the continuous analogue, where the sum becomes an integral. At fixed theta the log evidence is constant in q. Read the KL direction aloud. On the left, both densities coincide.
